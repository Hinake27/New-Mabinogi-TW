# 新瑪奇計算器

新瑪奇計算器是一個以瀏覽器執行的靜態工具頁，整合常用的遊戲數值換算與手續費試算功能，適合在日常交易、銀行操作與拍賣估算時快速使用。

本專案目前採單一 `index.html` 形式建置，不需安裝套件，也不依賴後端服務。只要以瀏覽器開啟即可使用。

## 功能概要

本工具目前提供以下三項主要功能：

1. `台幣 / 遊戲幣雙向換算`
2. `銀行手續費試算`
3. `拍賣實收金額試算`

另有以下輔助功能：

1. `深色 / 淺色紙本主題切換`
2. `中文單位金額顯示`
3. `每個工具內建小計算機`
4. `中文快捷單位按鍵（千 / 萬 / 億）`

## 各工具說明

### 1. 台幣 / 遊戲幣雙向換算

可依需求切換以下兩種方向：

1. `台幣推算遊戲幣`
2. `遊戲幣反推台幣`

可直接輸入：

1. 換算金額
2. 匯率數值

適用情境：

1. 快速估算遊戲幣購買成本
2. 反推遊戲幣出售對應台幣金額
3. 配合自訂匯率做即時比較

### 2. 銀行手續費試算

提供常見銀行操作的試算結果，包含：

1. 現金存入
2. 現金提領
3. 支票開立
4. 支票存入

可依條件套用週三折扣，協助比較一般情況與折扣情況下的實收或實付金額。

### 3. 拍賣實收金額試算

用於估算拍賣成交後的最終收益，提供不同拍賣類型的結果比較，並可選擇是否將支票相關費用一併納入計算。

適用情境：

1. 上架前先估算實收金額
2. 比較不同拍賣類型的差異
3. 配合銀行支票成本一併評估

## 小計算機功能

每個工具下方皆附有獨立小計算機，可直接輔助輸入數值。

支援內容：

1. 四則運算：`＋` `−` `×` `÷`
2. 快速清除與刪除
3. `=` 即時計算
4. `帶入欄位` 直接填入目前工具的輸入欄位
5. 中文快捷單位：`千`、`萬`、`億`

範例：

1. 輸入 `5` 後點選 `萬`，會自動轉為 `50000`
2. 輸入 `12` 後點選 `億`，會自動轉為 `1200000000`

## 顯示規則

為了提升閱讀效率，目前頁面中的金額顯示採以下規則：

1. 主要結果區以中文單位顯示
2. 輔助數值區保留原始數字格式
3. 小計算機輸入值可直接帶入各工具欄位

## 使用方式

### 直接開啟

1. 以瀏覽器開啟 [index.html](/C:/Users/Administrator/Desktop/瑪奇工具/New-Mabinogi-TW-main/index.html)
2. 選擇所需工具頁籤
3. 輸入數值或使用小計算機輔助輸入
4. 檢視試算結果

### 本機預覽

若需要以本機伺服器方式預覽，可在專案目錄執行：

```powershell
py -m http.server 4173
```

之後於瀏覽器開啟：

```text
http://127.0.0.1:4173
```
